SENWEI · Zeabur 環境變數（你只要貼一次）

1) 本機在專案根目錄備好 `.env`（可從 `.env.example` 複製並填入密碼；`.env` 不會進 Git）。

2) 產生給 Zeabur 貼上的內容（會略過 PORT、略過註解）：
   npm run zeabur:print-env

   或在 Mac 複製到剪貼簿：
   npm run zeabur:print-env | pbcopy

3) Zeabur → SENWEI → recycle-dpp-platform → 環境變數 →「Edit as Raw」
   貼上 → 儲存 → 重新部署。

   【502】刪除使用者變數裡的 PORT=3000；讓平台注入 PORT，或依程式在未注入時聽 8080。

4) Logs 應有：[bootstrap] DB target ... database=zeabur
   與 listening on http://0.0.0.0:...

5) UPLOAD_DIR=/data 須與硬碟掛載路徑一致。預覽 404 請在同頁重新上傳圖片。

6) lockdown-install.js / SES 多為擴充或 Zeabur 站台腳本，與本專案無關。

※ 密碼曾外流請改 MySQL 密碼並更新 .env 與 Zeabur 變數。
