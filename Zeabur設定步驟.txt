SENWEI · Zeabur 環境變數（你只要貼一次）

你無法從 Git 自動帶密碼上雲，請照下面做「一次」即可。

1) 在本機專案目錄執行（會印出整份設定）：
   npm run zeabur:print-env

   或在 Mac 直接複製到剪貼簿：
   npm run zeabur:print-env | pbcopy

2) 打開 Zeabur → 專案 SENWEI → 服務「recycle-dpp-platform」→「環境變數」
   → 點「Edit as Raw」（批次編輯）

3) 把剪貼簿內容整段貼進去 → 儲存 → 觸發重新部署

   【若出現全站 502】到「環境變數」刪除或清空「PORT」這一項，讓 Zeabur
   自動注入埠號（貼了 PORT=3000 會蓋掉平台設定，反向代理連不到 App）。

4) 部署完成後看 Logs，應出現：
   [bootstrap] DB target host=... database=zeabur
   以及 [recycle-dpp-platform] listening on http://0.0.0.0:XXXX（XXXX 多為 8080）
   若 database= 不是 zeabur，請檢查貼上的 MYSQL_DATABASE。

5) 上傳圖片需與硬碟掛載一致：UPLOAD_DIR=/data（已含在 .env.zeabur）

※ .env.zeabur 不要提交 Git（已在 .gitignore）。密碼若曾外流請在 Zeabur MySQL 裡改密碼後更新面板變數。
